- แพลตฟอร์ม: Roblox
- แนวเกม: **ภารกิจหนีภัยแบบ co-op** — ผู้เล่นทั้งทีมต้องทำภารกิจร่วมกัน (เช่น ซ่อมเครื่อง ปลดล็อกทางออก ช่วย NPC) ขณะที่ภัยพิบัติรุนแรงขึ้นเรื่อยๆ แล้วหนีออกให้ได้
- ธีม: **A = ภัยพิบัติ** ทำให้เสร็จก่อน; **B = Sci-fi** ทำต่อถ้ามีเวลา → ระบบทั้งหมดต้องออกแบบให้เปลี่ยนธีมได้โดยใช้ระบบเดิม (ธีมเป็น "ข้อมูล/คอนเทนต์" ไม่ใช่โค้ดคนละชุด)
- ตัวละครผู้เล่น: **หนูแฮมสเตอร์** (ชื่ออื่นของโปรเจกต์: "Roblox Hamster Conquror the world")
- สเกลโลก: **แฮมสเตอร์ตัวจิ๋วในโลกของคน** — แมพเป็นสถานที่ของคน (บ้าน, ร้านสัตว์เลี้ยง, แล็บ ฯลฯ) ของใช้คนกลายเป็นสิ่งกีดขวางยักษ์

- กลุ่มเป้าหมาย: **กลุ่มเพื่อนทุกวัย** → ไม่มีความรุนแรงเลือดสาด, เล่นง่าย, รองรับมือถือ

- **เดดไลน์: 25 ต.ค. 2026 12:00 (BKK)** ส่ง เกมที่ publish แล้ว + เอกสาร + วิดีโอ → สร้างตาม GDD §8 Deadline build และแผนรายชั่วโมง §8.9

## เส้นทางของงานหนึ่งชิ้น

1. Lead เขียนโจทย์: เป้าหมาย, ไฟล์ที่ต้องส่ง, เกณฑ์ผ่าน
2. Agent ฝ่ายผลิตทำงาน และระบุ "สมมติฐานที่ตั้งเอง" ไว้ท้ายงานเสมอ
3. Reviewer ตรวจโดยดูแค่ผลงาน + เอกสารกลาง (ไม่เห็นกระบวนการคิดของคนทำ)
   คำตัดสิน: **PASS / PASS WITH FIXES / FAIL** พร้อมรายการแก้ เรียงตามความรุนแรง (Blocker / Major / Minor)
4. แก้ได้ไม่เกิน 2 รอบ — ถ้ายังไม่ผ่าน Lead ยกให้ Boss ตัดสิน
5. Lead รวมงาน ส่ง Boss เป็นรายงานสั้น + เรื่องที่ Boss ต้องตัดสิน (ไม่เกิน 3 ข้อ)

## Milestones

- **M0 แผน**: GDD + สถาปัตยกรรมโค้ด → Boss อนุมัติก่อนเขียนโค้ด
- **M1 ต้นแบบเล่นได้**: ภารกิจ 1 ด่าน, ภัยพิบัติ 1–2 แบบ, HUD พื้นฐาน
- **M2 ขยาย**: ภัยพิบัติ/ภารกิจเพิ่ม, รางวัล, เซฟข้อมูล
- **M3 ขัดเกลา**: บาลานซ์, เสียง/เอฟเฟกต์, แก้บั๊ก
- **Theme B**: Sci-fi บนระบบเดิม
