# หน้าเกมบน Roblox — ข้อความ + brief รูป

**We R in Trouble 🐹 Hamster Disaster Escape**

## 4. ตั้งค่าที่เกี่ยวข้อง (เช็คก่อน publish)
- Max players: **4** · Genre: Adventure / Survival (ตามที่ Creator Hub มีให้เลือก) · อุปกรณ์: Computer, Phone, Tablet
- Maturity & Compliance questionnaire กรอกแล้ว · audio/asset ทุกตัวใช้ได้กับ place นี้
- Access: **Public** · ทดสอบเข้าเกมจากบัญชีอื่น/มือถือ
