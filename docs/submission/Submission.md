## 1. สรุปโปรเจกต์

**Pitch:** ทีมแฮมสเตอร์ 2–4 ตัวถูกลืมไว้ใน **ครัวตอนเที่ยงคืน** ขณะที่บ้านเกิด **แผ่นดินไหว** ต้องแยกกันไปวิ่งวงล้อปั่นไฟและหาถ่านก้อนยักษ์มาเสียบแท่นชาร์จ แล้วปีนขึ้นเคาน์เตอร์ไป **กดวิทยุของเล่นพร้อมกันทั้งทีม** เพื่อเรียกนักดับเพลิง เมื่อหน้าต่างเปิด ต้องเอาตัวรอดบนขอบหน้าต่างระหว่างรอ **กรงสัตว์เลี้ยงหย่อนลงมารับ** — ยิ่งช้า ภัยยิ่งแรง และแฮมสเตอร์ที่ "มึน" ลุกเองไม่ได้ ต้องให้เพื่อนกลับไปช่วย

## 2. วิธีเล่น

**ต้องมีผู้เล่น 2–4 คน / Needs 2–4 players** — เข้า server เดียวกัน รอใน Lobby (แท่นลอย) ครบ 2 คนแล้วนับ 30 วินาที

### ปุ่มควบคุม
| การกระทำ | PC | มือถือ |
|---|---|---|
| เดิน | WASD | จอยสติ๊กซ้าย |
| กระโดด | Space | ปุ่มกระโดด |
| กดใช้ / หยิบ / กดค้าง | **E** (ค้างไว้เมื่อต้องกดค้าง) | แตะ (ค้าง) ที่ปุ่ม prompt |
| ซ่อน/แสดง HUD | H | ปุ่ม 👁 มุมขวาบน |

ไม่มีปุ่มวิ่งและปุ่มวางของ — ของตกเองเมื่อแฮมสเตอร์ล้ม

### เป้าหมาย (2 Step + Extraction)
1. **Step 1 "Power up the charger"** (ทำคู่กัน)
   - **วิ่งวงล้อ** — กดค้างที่วงล้อ ~45 วินาที (2 คนช่วยกันเร็วขึ้น)
   - **ส่งถ่าน** — หาถ่าน AA ยักษ์ในโซนต่างๆ (โต๊ะกินข้าว, ชั้นรองเท้า, หน้า pantry) แล้วเอาไปเสียบแท่นชาร์จ (จำนวน = จำนวนผู้เล่น สูงสุด 3)
2. **Step 2 "Call for help"** — ปีนทางลาด (เขียง → ตำราอาหาร) ขึ้นเคาน์เตอร์ แล้ว **ทุกคนกดค้างวิทยุคนละเครื่องพร้อมกัน** สะสมเวลา 45 วินาที (Billboard บอก "Held 2/2") — ถ้าทีม 3–4 คนรอนานเกิน 75 วินาที ระบบลดจำนวนที่ต้องกดลง 1 (Emergency override)
3. **Extraction** — หน้าต่างเปิด! แผ่นดินไหวแรงที่สุด (Big Shake) รอนักดับเพลิง **60 วินาที** แล้วกรงสัตว์เลี้ยงจะหย่อนลงมาที่กระบะดอกไม้นอกหน้าต่าง → ทุกคนเข้าไปในกรงแล้วอยู่ให้ครบ **10 วินาที** = หนีสำเร็จ

### ภัยพิบัติ 4 Stage
Calm → Warning (Banner "EARTHQUAKE!") → Active → Critical — **วงแดงบนพื้น** เตือนก่อนแอปเปิล/กระป๋องยักษ์ตกลงมา "โป๊ก!" (ทำ damage) พื้นสั่นทำให้เดินช้าลง

### ล้ม / ช่วยเพื่อน
- HP หมด → **Downed** (ม้วนตัว + ดาวหมุน) ลุกเองไม่ได้ มีเวลา 30 วินาที
- เพื่อนเดินไปกดค้าง **Revive 4 วินาที** เพื่อช่วย
- ไม่มีใครช่วยทัน → **Eliminated** (เอฟเฟกต์ "ปุ๊ฟ" ขนฟู) แล้ว respawn ใน 15 วินาที

### ชนะ / แพ้
- **ชนะ**: ทีมเข้ากรงครบแล้วกรงออกตัว → กล้องตอนชนะ + Result
- **แพ้ Collapse**: หมดเวลา 7:00
- **แพ้ Wipe**: ทุกคนล้มพร้อมกัน

`[ภาพ 1: Lobby — แฮมสเตอร์ 2 ตัวบนแท่น HUD ขึ้น "Waiting for players" / นับถอยหลัง]`
`[ภาพ 2: HUD ระหว่างเล่น — Stage + timer, รายการ objective, world marker (ใช้ประกอบหัวข้อวิธีเล่น)]`

## 3. ฟีเจอร์เด่น

1. **Co-op ที่บังคับจริงด้วยกลไก** — วิทยุต้องกดพร้อมกันทุกคน (MultiHold แบบสะสม) ไม่มีใครแบกทีมคนเดียวได้ จำนวนงานปรับตามขนาดทีม (2/3/4 คน) และมี fallback เมื่อเพื่อนออกกลางเกม จึงไม่มี softlock
2. **ภัยพิบัติแบบสุ่ม + 4 Stage** — ความรุนแรงเพิ่มตามเวลาและความคืบหน้า ทุกความเสียหายมี telegraph (วงแดง) ≥ 1 วินาที เด็กเข้าใจได้โดยไม่ต้องอ่าน
3. **Rescue Moment** — ฉากไคลแมกซ์: Big Shake, ไฟกู้ภัยแดง/น้ำเงินสาดผ่านหน้าต่าง, ไซเรน, กรงหย่อนลงมาพร้อมไฟฉาย และกล้องตอนชนะ
4. **Downed / Revive** — ล้มแล้วต้องให้เพื่อนกลับมาช่วย สร้างจังหวะ "เดี๋ยวไปช่วย!" ระหว่างเพื่อน
5. **สเกลแฮมสเตอร์ในโลกคน** — ตู้เย็น โต๊ะ เก้าอี้ ตำราอาหาร กลายเป็นภูเขาและทางลาด
6. **รองรับมือถือ** — ปุ่มแค่ เดิน/กระโดด/กดใช้, HUD ใช้ Scale, ปุ่มสัมผัส ≥ 44 px
7. **ระบบที่เปลี่ยนธีมได้ด้วย data** — โค้ดรู้จักแค่ Hazard component / Objective kind / Stage แบบ generic ชื่อธีม (แผ่นดินไหว, ถ่าน, วิทยุ, แฮมสเตอร์) อยู่ในไฟล์ data — เพิ่มภัย/แมพ/ธีม Sci-fi ได้โดยไม่เขียนระบบใหม่

`[ภาพ 3: แฮมสเตอร์บนพื้นครัว มองขึ้นไปเห็นโต๊ะ/ตู้เย็นยักษ์ — โชว์สเกล]`
`[ภาพ 4: วิ่งวงล้อ + Billboard progress บนวงล้อ]`
`[ภาพ 5: แฮมสเตอร์ถือถ่าน AA เรืองแสงเดินไปแท่นชาร์จ]`
`[ภาพ 6: 2 ตัวกดวิทยุคนละเครื่องบนเคาน์เตอร์ Billboard "Held 2/2" (ถ้ามี: "Held 4/4")]`
`[ภาพ 7: Banner "EARTHQUAKE!" + วงแดงบนพื้น + แอปเปิลกำลังตก]`
`[ภาพ 8: ตัวหนึ่ง Downed ดาวหมุน อีกตัวกำลัง Revive (เห็นแถบ progress)]`
`[ภาพ 9: Rescue Moment — ไฟแดง/น้ำเงินนอกหน้าต่าง กรงกำลังหย่อนลงมา (ซ่อน HUD)]`
`[ภาพ 10: Result screen ชนะ]`

## 4. ทีมและ workflow

### ทีม
โปรเจกต์นี้ทำโดย **Boss (ผู้ใช้ — dev คนเดียวใน Roblox Studio)** ร่วมกับ **ทีม AI agent** ที่แบ่งบทบาทเหมือนสตูดิโอเกมจริง:

| บทบาท | หน้าที่ |
|---|---|
| **Boss** | ตัดสินทิศทาง ความสนุก ธีม ลำดับความสำคัญ · build/playtest ใน Studio · อนุมัติงานทุกชิ้น |
| **Lead** | แตกงาน เขียนโจทย์ให้แต่ละ agent รวมงาน คัดกรอง สรุปให้ Boss พร้อม "เรื่องที่ต้องตัดสิน" ไม่เกิน 3 ข้อ · เขียนเอกสารส่งงาน/storyboard |
| **Game Designer** | GDD, core loop, กลไก, ตัวเลขบาลานซ์และ pacing |
| **Gameplay Scripter** | Round / Mission / Objective / Disaster / Extraction (server) |
| **Systems/Data** | Remotes, Config, Player state, Items, debug commands, anti-exploit |
| **UI/UX** | HUD 8 ชิ้น, world marker, Result, ปุ่มซ่อน HUD, รองรับมือถือ |
| **Level Designer** | สเปกแมพ Midnight Kitchen, จุดภารกิจ, เส้นทาง, จุด spawn/NoImpact |
| **Art & Audio** | สเปกแฮมสเตอร์, props, เสียง, lighting 4 preset, Rescue Moment |
| **QA/Playtest** | Checkpoint CP0–CP4, smoke test, edge cases, bug template |
| **Code Reviewer** | ตรวจโค้ดอิสระ (ไม่ได้เขียนโค้ดชุดนั้น) |
| **Design Reviewer** | ตรวจงานออกแบบอิสระ |

### เส้นทางของงานหนึ่งชิ้น: produce → review → fix → Boss approve
1. **Lead เขียนโจทย์** — เป้าหมาย ไฟล์ที่ต้องส่ง เกณฑ์ผ่าน
2. **Agent ฝ่ายผลิตทำงาน** และเขียน "สมมติฐานที่ตั้งเอง" ไว้ท้ายงานเสมอ
3. **Reviewer อิสระตรวจ** โดยเห็นแค่ผลงาน + เอกสารกลาง (ไม่เห็นกระบวนการคิดของคนทำ) ตัดสิน **PASS / PASS WITH FIXES / FAIL** พร้อมรายการแก้ระดับ Blocker / Major / Minor
4. **แก้ได้ไม่เกิน 2 รอบ** — ถ้ายังไม่ผ่าน Lead ยกให้ Boss ตัดสิน
5. **Boss อนุมัติ** จากรายงานสั้นของ Lead

### ตัวอย่างจริงจาก `docs/reviews/`
| รอบ | งาน | คำตัดสิน | เกิดอะไรขึ้น |
|---|---|---|---|
| GDD review 1 | GDD v0.1 | **FAIL** (Blocker 1, Major 13, Minor 9) | Reviewer คำนวณ pacing จากตัวเลขใน GDD เองแล้วพบว่า **ทีมหนีออกได้ใน ~1:00–1:10 ก่อนภัยพิบัติเริ่มทำ damage** = ขัดกับแนวเกม → Game Designer เพิ่มตาราง pacing budget, Extraction ETA 60s, วงล้อ 45s, จำนวนถ่านตามจำนวนผู้เล่น |
| GDD review 2 | GDD v0.2 | **PASS WITH FIXES** | ยืนยันว่าแก้ครบทั้ง 23 ข้อ แต่พบ Major ใหม่ 3 ข้อ เช่น วิทยุ (MultiHold) จะชนะไม่ได้ถ้ามีคนไม่ยอมช่วย → เพิ่ม Emergency override |
| GDD review 3 | GDD v0.3 (Deadline build) | **PASS WITH FIXES** | ตรวจเฉพาะเรื่องส่งงานทัน: พบ D1–D9 เช่น ช่องโหว่ spawn บนขอบหน้าต่างเป็นจุดปลอดภัยถาวร, shot list วิดีโอต้องใช้ 4 คนแต่รับประกันได้แค่ 2 → storyboard เปลี่ยนเป็นแฮมสเตอร์ 2 ตัว, ย้ายการตั้งค่า compliance ของ Roblox มาทำตั้งแต่ชั่วโมงแรก → **Boss อนุมัติ GDD v0.4** |
| Code review 1 | `src/**` ก่อน sync เข้า Studio | **PASS WITH FIXES** (0 Blocker, Major 3, Minor 8) | `luau-lsp --!strict` 0 error · พบว่า Studio Local Server จะเริ่มเกมคนเดียวเสมอ (QA จะรายงาน Blocker ปลอม), ภัยพิบัติปิดไม่ได้ตอน CP1, StreamingEnabled อาจทำให้ตกแมพบนมือถือ → เพิ่ม dev switch `DevMinPlayers` / `DevNoHazards` (Studio เท่านั้น) |

หลังจากนั้น QA ใช้ **Checkpoint CP0–CP4** (Boss เล่นเทสต์เองทุก CP) พร้อม **ลำดับตัด** ที่วางไว้ล่วงหน้า ถ้า CP ไหนไม่ผ่านตามเวลา และมี Feature freeze / Code freeze ที่เลื่อนไม่ได้

## 5. เทคโนโลยี

| | |
|---|---|
| ภาษา | **Luau** (`--!strict` ทุกไฟล์) ตรวจด้วย `luau-lsp analyze` + `selene` lint ก่อนส่งทุกครั้ง |
| Workflow | **Rojo + GitHub** — โค้ดทั้งหมดเป็นไฟล์ `.luau` ใน repo แล้ว sync เข้า Studio (ไม่ได้เขียนสคริปต์ใน Studio ตรงๆ) |
| สถาปัตยกรรม | **Server-authoritative**: server เป็นเจ้าของ state ทั้งหมด — HP, ความคืบหน้า objective, ตำแหน่ง item, ตัวคูณความเร็ว, Stage ภัยพิบัติ client แค่อ่าน Attribute มาแสดงผลและส่ง "เจตนา" ผ่าน Remotes ที่ server validate ทุกครั้ง |
| Server-timed hold | กลไกเดียวใช้กับวงล้อ วิทยุ และ revive — server จับเวลาเอง client โกงเวลาไม่ได้ |
| Data-driven | Mission / Objective / Item / Disaster / Stage อยู่ใน `src/shared/Config/` (ห้าม hard-code ตัวเลข) ภัยพิบัติประกอบจาก Hazard component แบบ generic (`Pulse`, `TelegraphedImpact`, `MoveModifier`, `ScreenEffect`) |
| Debug | คำสั่ง `/dbg` (`skipStep`, `setStage`, `unlockExit`, `setHP`, `spawnDummyHolder`, `endMatch`) ทำงานเฉพาะใน Studio / บัญชี dev — server ตรวจทุกครั้ง ใช้บน live ไม่ได้ |
| Services (server) | RoundState → Map → PlayerState → Hold → Revive/Item → Disaster/Mission → Extraction → Round → Debug (ลำดับ dependency ไม่มี require วน) |

## 6. ข้อจำกัดที่รู้ (Known limitations)

- **ต้องมีผู้เล่น 2–4 คน** — ไม่มีโหมดเล่นคนเดียว (Boss ตัดสินใจเพื่อให้ co-op เป็นหัวใจของเกม)
- ภัยพิบัติที่ทำงานครบตอนนี้มี **Earthquake อย่างเดียว** (ระบบสุ่มพร้อม เพิ่ม Flood ได้ด้วย data)
- แมพเป็น **Deadline cut** (2 ระดับ) ของแมพครัวเต็ม
- ไม่มีวิ่ง / ปุ่มวางของ / เซฟข้อมูล / รางวัล / ร้านค้า / tutorial
- ของที่ตกจากแผ่นดินไหวเป็น **ภาพอย่างเดียว** (ไม่ชนตัวละคร) เพื่อกันการติด/ถูกเหวี่ยง
- ตัวละครแฮมสเตอร์ใช้ R15 + accessory (ยังไม่ใช่ custom rig) animation/VFX ยังเป็นแบบพื้นฐาน
- ข้อความในเกมเป็นภาษาอังกฤษ
- `[บั๊กที่รู้จากผล CP4 / playtest — Lead เติมก่อนส่ง]`
