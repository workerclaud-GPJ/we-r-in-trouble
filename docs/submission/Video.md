## 2. Recording tips

### อุปกรณ์/ตั้งค่า
- อัดด้วย **OBS** (1920×1080, 60 fps, CQP/CRF ~18) หรือตัวอัดของ Roblox — Graphics Quality ตั้งสูงสุด, ปิด notification ของเครื่อง
- **ทั้ง 2 คนอัดหน้าจอของตัวเองพร้อมกัน** เพื่อมี footage 2 มุมสำหรับ split-screen (ช็อต 5) และตัดสลับ (ช็อต 3)
- กล้อง: ซูมเข้าใกล้ตัวละคร มุมต่ำ เพื่อโชว์สเกล "ของยักษ์" · เคลื่อนกล้องช้าๆ นุ่มๆ (คลิกขวาค้างลาก)
- อัดแต่ละช็อต **ยาวกว่าที่ต้องใช้ 3–5 วินาที** (หัว-ท้าย) เผื่อตัดต่อ

### ซ่อน HUD
- **PC: กด H** = ซ่อน/แสดง HUD ทั้งหมด (marker ซ่อนตาม) — ใช้กับช็อต 1, 7, 8 · ระวัง: กดตอนพิมพ์แชตจะไม่ทำงาน
- มือถือ: ปุ่ม 👁 มุมขวาบน (จางเกือบมองไม่เห็นตอนซ่อน แต่ยังแตะได้)
- ซ่อนแชต Roblox และ leaderboard ด้วย (ปุ่มเมนูของ Roblox) ก่อนอัดช็อตสวย

### Debug commands — **Studio เท่านั้น** (บน live ใช้ไม่ได้ ยกเว้นบัญชี dev)
พิมพ์ในแชต: `/dbg <command>`

| คำสั่ง | ใช้ถ่ายช็อต |
|---|---|
| `/dbg setStage Critical` | ไปที่ภัยแรงสุดทันที (ช็อต 4, 7) — `setStage Active` สำหรับของตกแบบปกติ |
| `/dbg unlockExit` | ข้าม Step ไปเปิดหน้าต่างทันที → Big Shake + ไฟกู้ภัย + ETA → **ถ่าย Rescue Moment ซ้ำได้เร็ว** |
| `/dbg skipStep` | ข้าม Step ปัจจุบัน |
| `/dbg setHP 1` | ให้ล้มง่ายสำหรับช็อต Downed/Revive (ช็อต 6) |
| `/dbg spawnDummyHolder A` (A–D) | holder ปลอมบนวิทยุ → ถ่าย Billboard "Held 4/4" (ช็อตทางเลือก 5) |
| `/dbg endMatch win` | ไป Result ชนะเร็ว |

ลำดับแนะนำสำหรับ Rescue Moment ใน Studio: Local Server 2 Players (หรือ Attribute `DevMinPlayers = 1` บน ServerStorage ถ้าอัดคนเดียว) → เข้า Match → เดินไปยืนบนเคาน์เตอร์ใกล้หน้าต่าง → กด **H** → `/dbg unlockExit` → อัด 75s ต่อเนื่องจนกรงมาและกล้องชนะ
**ห้ามเซฟ/publish place พร้อม Attribute `DevMinPlayers` / `DevNoHazards`**

### Footage จริงบน live (21:00–22:30 วันที่ 24 + pickup 09:00 วันที่ 25)
- อัด **ทุก Match** ทั้ง 2 คน (≥ 3 Match) — ช็อตที่ดีที่สุดมักเกิดเองจากการเล่นจริง (ล้มจริง, ช่วยจริง, ตะโกน)
- ใน 1 Match ทำตาม storyboard: แบ่งงานวงล้อ/ถ่าน → ขึ้นเคาน์เตอร์ด้วยกัน → ให้ตัว B "ยอม" โดนของตก 1 ครั้งเพื่อช็อต revive
- ช็อตที่ debug ช่วยไม่ได้ (2 คนกดวิทยุจริง) ต้องได้จาก live หรือ Studio + dummy
