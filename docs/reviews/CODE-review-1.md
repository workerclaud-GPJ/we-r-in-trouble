## สิ่งที่ตรวจแล้วผ่าน (ให้ Lead ใช้ตัดสิน ไม่ต้องตรวจซ้ำ)

1. **Boot**: `default.project.json` → `ReplicatedStorage.Shared` / `ServerScriptService.Server` / `StarterPlayerScripts.Client` ตรงกับ require ทุกตัว (`script.Parent.Parent.Types` ใน Config/*, `script.Parent.Parent.PlayerStateService` ใน Objectives/*) ไฟล์ entry มี 2 ตัวและ suffix ถูก (`Main.server.luau`, `Main.client.luau`), `Config/init.luau` → ModuleScript ไม่มี require วนกัน (ลำดับ: RoundState → Map → PlayerState → Hold → Revive/Item → Disaster/Mission → Extraction → Round → Debug) `CharacterAutoLoads = false` ตั้งทั้งใน project และ `PlayerStateService.start()`; `PlayerAdded` + loop `GetPlayers()` (รองรับ Play Solo ที่ผู้เล่นเข้ามาก่อน script) → `setLobby` → `LoadCharacterAsync` (มีใน defs ส่วน `LoadCharacter` deprecated มี fallback ไว้) → `PivotTo` LobbySpawn
2. **CP0/CP1 flow**: Lobby/Intermission (หยุดนับเมื่อจำนวนตก) → `loadMap` (unload ก่อนเสมอ = Map มีแค่ 1) → spawn → Step 1 (Repair + Deliver ทำคู่กัน) → `advance` เปิด Step 2 ใน tick เดียวกัน → MultiHold → `ExitUnlocked` (connection อยู่ใน match scope) → ETA 60 → กรง → Departure (หยุดได้ ไม่รีเซ็ต) → Ending 3s → Result 15s → `cleanupMatch` → `setLobby` ทุกคน → รอบ 2 `skipStep`/`unlockExit` ทำทีละ step ถูกต้อง (re-entrancy ของ `markDone→advance→openStep` ตรวจแล้ว) error ระหว่าง Match ถูก pcall แล้ว cleanup ไม่ค้าง
3. **Security**: Remote ขาเข้ามี 2 ตัว — `ActivityPing` (rate limit 5s, แค่รีเซ็ต AFK) และ `DebugCommand` (type, ความยาว ≤ 64, ≤ 5/s, `allowed()` เช็ค `IsStudio()`/allowlist **ทุกครั้งฝั่ง server**; `DEV_USER_IDS` ว่าง → บน live ใช้ไม่ได้กับทุกคน, TextChatCommand ไม่ถูกสร้างบน live) `DebugInvoke` อยู่ใน ServerStorage (client เข้าถึงไม่ได้) ทุก prompt handler เช็คซ้ำฝั่ง server: participant, Standing, ระยะ ≤ 10, step เปิด, ชนิด item client เขียน HP/State/progress ไม่ได้ (attribute ฝั่ง client ไม่ replicate)
4. **Leaks**: timer ทุกตัวมี token/scope guard (`eliminate` respawn/poof, lobby reload, impact `scope:alive()`, extraction `task.delay` ถูก cancel ผ่าน Cleanup) `HoldService.reset`, `ItemService.reset`, `ReviveService.reset`, objective `destroy()` ตัด connection ครบ; character connections ถูกล้างทุกครั้งที่โหลดตัวใหม่
5. **UI contract**: ชื่อ attribute ใน `StateAdapter.luau` มาจาก `Contract.luau` ทั้งหมด ตรงกับ ARCHITECTURE §3–§6 Banner จาก server กับ banner ที่ client derive เองไม่ซ้ำ (dedupe ตาม key 8s) tag/attribute ใน `BuildMidnightKitchen.luau` ตรงกับ Contract (ObjectiveAnchor + PromptPart + `Part` A–D, ItemSpawn ×6 ใน 3 Zone, PlayerSpawn Priority/EnabledBy, LockedDoor, ExitZone, ExitVehicleSpot, NoImpact, WinCameraPoint, KillY) กำแพง/เพดานล่องหน `CanQuery = false` ตรงกับ raycast `RespectCanCollide`
6. **API**: ใช้ `task.*`, `GetServerTimeNow` สำหรับค่า `*At` ทุกตัว, `os.clock` สำหรับ dt, Prompt `HoldDuration = 0` + `Triggered`/`TriggerEnded` (server re-check ระยะทุก 0.1s), `SetStateEnabled(Dead, false)` ทั้งฝั่ง server และ client, `ResetButtonCallback = false` (retry), RaycastParams Exclude ตัวละคร + Runtime
