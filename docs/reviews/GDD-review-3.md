## 4. หัวข้อ 8: สร้างได้ใน ~30 ชั่วโมงไหม

**สร้างได้ แต่ตึง** ขอบเขตตัดมาถูกแล้ว ทั้ง 3 objective ใช้กลไก hold ตัวเดียว ภัยมีแค่ Earthquake ที่ใช้ 3 component และ debris เป็นภาพอย่างเดียว (ลดความเสี่ยงฟิสิกส์ได้มาก) ไม่มีวิ่ง/Drop/Inactive/Continuous และ checkpoint กับ freeze ก็ชัดเจน สิ่งที่ต้องมีเพื่อให้เล่นได้และส่งได้มีครบ: Lobby, เงื่อนไขเริ่ม (2 คน / solo), ชนะ/แพ้ 3 แบบ, Result, cleanup ข้ามรอบ และมือถือ

ข้อแนะนำเพื่อลดความเสี่ยง (ไม่ต้องแก้ GDD แค่ให้ Lead สั่งงาน):
- **Emergency override และ Last call** ทำหลัง CP2 เท่านั้น (ตอนนี้อยู่ลำดับตัดที่ 2–3 อยู่แล้ว) เพราะสำคัญกับเซิร์ฟเวอร์สาธารณะที่มีคนแปลกหน้า แต่ไม่ค่อยมีผลกับการตรวจงานที่จะเล่นคนเดียวหรือเล่นกับเพื่อน
- **กล้องตอนชนะ + lighting 4 preset** เป็นงานภาพที่กินเวลา Boss ให้ทำหลัง CP3 ถ้าไม่ทัน ใช้ลำดับตัดข้อ 4–5 ได้เลย
- งานที่เพิ่มจาก D1–D9 รวมแล้ว < 2 ชั่วโมง (D4 เป็นงานของ Boss ~20 นาทีที่ H0)
